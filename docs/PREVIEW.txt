PNGTUBER MAX by Clatasha — 0.1.2 DEVELOPMENT PREVIEW

Extract the complete folder and open PNGTuberMax.exe. Keep the resources and DLLs together.
Requires Windows 10/11 x64 with .NET Framework 4.8. No OBS or another PNGTuber app is needed.
This product includes software developed by Rahisaurus. This is a modified RahiTuber-based app.

BLUE MAX DESIGN
New Inter typography, raised controls with shadows and edge highlights, a branded header,
blue panels, and 30 original action icons. Hover controls to see their descriptions.
The inherited sprite manager, motion/physics, talking/blinking states and shortcuts remain.
Use Make Portable to move an existing XML character setup with its referenced PNG assets.
Your private DERSPAWN artwork is not shipped in this application.

VIRTUAL CAMERA — EXPERIMENTAL DIRECTSHOW BACKEND
Click Camera setup once and approve the Windows administrator request.
Setup runs without a visible PowerShell window and shows its result in Camera Preferences.
Restart the receiving app and select PNGTuber Max Camera. Press Start virtual camera.
The camera sends the avatar scene only, with an opaque navy background and aspect-preserving
letterboxing at 640x480 / 30 FPS. Editor controls, shadows and tooltips are excluded.
Camera output is off each launch; regular app use does not require elevation.
The camera source may not work with Media Foundation-only receiving apps.
Do not use two instances to publish the same camera. Another instance remains usable for editing.

Close the receiving app before removing/updating the camera component.
To remove it, run Uninstall-Camera.ps1 as administrator. Saved characters remain.

PLANNED
Front/back plush PNG mode, surface attachments, local face tracking and live eye/mouth cutouts
have not been ported into this new foundation yet.

VALIDATION
The automated Windows build checks layout, audio-meter thresholds and the frame contract.
It also registers the camera and tests real DirectShow frame delivery with a simulated publisher.
Compilation does not establish webcam compatibility or the visual appearance on your machine.
Receiving-app and Windows visual tests are required before using this preview for a live stream.

0.1.2 CHANGES
The editor is split into left studio/layers, middle avatar preview, and right Preferences.
Preferences remain visible; choose a settings section using the selector at the top.
Imports/open/save use Windows file dialogs. Ctrl+Open merges into the current project.
Below the microphone selector, six blocks continuously display the raw selected-input peak.
Four green blocks, one amber, and one red cover quiet speech through levels near clipping.
The meter stays visible when advanced audio controls are collapsed.
Layer additions/duplicates are queued safely between UI frames; blank sprites cannot crash
selection-guide drawing. Folder copying uses stable identifiers while the list grows.
Camera setup repairs both Windows camera registrations, unblocks downloaded camera DLLs,
and records warnings separately from errors. Its result appears in Camera Preferences.
Use Check camera delivery to test registration and real DirectShow frame delivery.
If setup or checking fails, send the error text from the panel or camera-report.txt /
camera-install-log.txt in %LOCALAPPDATA%\Clatasha\PNGTuberMax.
